# AI Engineering Bootcamp – Sunday Project

## Project Overview

The purpose of this project is to clean and analyze sales data using Python, Pandas, and Matplotlib.

## Project Files

- `sales_raw.csv` – Original sales dataset.
- `Sunday_Project.ipynb` – Jupyter Notebook containing Part A and Part B.
- `cleaned_sales.csv` – Cleaned sales dataset generated in Part A.
- `sales_updated.csv` – Updated sales dataset generated in Part B.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Part A – Data Cleaning and Analysis

- Loaded and inspected the sales dataset.
- Handled missing values and duplicate records.
- Standardized region and category names.
- Handled invalid dates, prices, and quantities.
- Calculated revenue.
- Analyzed revenue by region and category.
- Created charts and identified key findings.
- Saved the cleaned data as `cleaned_sales.csv`.

## Part B – Data Updates

- Loaded the cleaned dataset.
- Calculated 5% tax.
- Increased Books category prices by 10%.
- Recalculated revenue and tax.
- Removed the selected transaction.
- Added and then removed the temporary `review_status` column.
- Saved and verified the final dataset as `sales_updated.csv`.

## How to Run the Project

1. Install Python on your computer.
2. Install the required libraries:

   pip install pandas matplotlib

3. Open the project folder in VS Code.
4. Open `Sunday_Project.ipynb`.
5. Select your Python kernel.
6. Run all notebook cells in order.

Make sure `sales_raw.csv` is in the same folder as the notebook.
